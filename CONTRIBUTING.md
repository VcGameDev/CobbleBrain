# Contributing to CobbleBrain

Thank you for considering contributing to CobbleBrain!  

## How to Contribute

1. **Fork the repository**  
   Click the "Fork" button on GitHub to create your own copy.

2. **Clone your fork locally**
   ```bash
   git clone https://github.com/VcGameDev/CobbleBrain.git
   cd CobbleBrain
   ```

3. **Create a new branch**
   ```bash
   git checkout -b feature/my-new-feature
   ```

4. **Make your changes**  
   - Follow the existing code style.  
   - Comment your code in English.  
   - Remove unused imports, variables, and dead code.
   - Ensure that your code does not negatively affect the AI’s behavior or its responses.
   - Test your changes in both singleplayer and multiplayer if possible.

5. **Commit and push**
   ```bash
   git commit -m "Add: short description of your change"
   git push origin feature/my-new-feature
   ```

6. **Open a Pull Request**  
   Go to your fork on GitHub and click "New Pull Request".

## Guidelines

- Keep commits small and focused.  
- Write clear commit messages.  
- If fixing a bug, reference the issue number.  
- Be respectful and constructive in discussions.

## Reporting Issues

- Use the **Issues** tab to report bugs or suggest features.  
- Provide as much detail as possible (Minecraft version, Fabric version, steps to reproduce)
- include the cobblebrain.json file and, if applicable, the crash-report file at \.minecraft\crash-reports\.  

Thanks for helping improve CobbleBrain!
